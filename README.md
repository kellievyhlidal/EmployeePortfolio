# Employee Performance Portfolio

## Overview

This project is a sanitized portfolio version of an employee performance tracking workbook I originally created while working in banking operations and branch leadership.

The goal was to give managers a practical, visual way to review performance across multiple KPIs, identify coaching opportunities, and track progress over time without manually piecing together several measures.

After I presented the original concept, regional leadership refined it and adapted a version for broader use across the region.

![Employee Performance Dashboard Preview](Employee_Performance_Dashboard_Preview.jpg)

## Business Problem

Performance data existed, but managers needed a faster way to turn individual metrics into a usable employee-level view. The workbook was designed to bring current performance, longer-term production, quality measures, coaching priorities, and career development into one repeatable dashboard.

## Solution

I built a multi-sheet Excel workbook with structured performance data, formula-driven calculations, a weighted performance model, trend analysis, and an employee coaching dashboard.

The public demo includes:

- 12 months of fictional employee performance data
- Core and secondary production goal tracking
- Quality, retention, and follow-up metrics
- Formula-driven weighted performance scoring
- 12-month production and benchmark tracking
- Monthly performance trend visualization
- Recent-win and coaching-focus sections
- Career goals, highlights, and promotion history
- A manager update guide for repeatable monthly use

## Tools & Skills Demonstrated

- Microsoft Excel
- Structured tables
- Lookup formulas
- SUMIFS and conditional calculations
- Weighted KPI modeling
- Date-based trend reporting
- Data validation and repeatable input design
- Dashboard design

## Business Impact

The original workbook helped organize performance information into a format that was easier to use during coaching and performance discussions. The concept was later reviewed and refined by regional leadership, and a version was adopted for broader regional use.

## Data Privacy

No customer information, confidential employee information, proprietary bank data, or internal scoring methodology is included in this repository. Names, locations, performance figures, benchmarks, terminology, and scoring weights in the demo are fictional.
