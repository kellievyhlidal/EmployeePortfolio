# Employee Performance Portfolio

## Overview

This project is a sanitized version of an employee performance tracking workbook I created while working in banking operations and branch leadership.

The goal was to give managers a simple, visual way to monitor employee performance across key sales and service metrics, identify coaching opportunities, and track progress over time.

After I presented the original workbook, regional leadership refined the concept and adapted a version for broader use across the region.

## Business Problem

Employee performance data was available, but managers needed a more practical way to organize and review multiple performance indicators in one place.

I designed this workbook to make performance trends easier to identify and to support more consistent coaching conversations.

## Solution

I built an Excel-based portfolio that consolidates employee performance information into a structured dashboard.

The workbook includes:

- Employee-level performance tracking
- KPI calculations and weighted scoring
- Goal attainment percentages
- Qualifying and account-opening metrics
- Follow-up tracking
- Rolling performance views
- Dropdown-based employee selection
- Structured Excel tables
- Automated formulas and lookup functions

## Tools & Skills

- Microsoft Excel
- XLOOKUP / lookup functions
- Structured tables
- Conditional calculations
- Data validation and dropdown controls
- KPI development
- Performance analysis
- Dashboard design
- Process improvement
- Operational reporting

## Business Impact

The portfolio helped organize performance information into a format that was easier to review and use during coaching and performance discussions.

The concept was later reviewed and refined by regional leadership, and a version of the portfolio was adopted for broader regional use.

## Data Privacy

All data included in this repository has been recreated or anonymized for portfolio purposes.

No customer information, confidential employee information, proprietary bank data, or other sensitive business information is included.
