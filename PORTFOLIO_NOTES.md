# Portfolio Demo Notes

This repository contains a recruiter-facing demonstration of an employee performance dashboard built in Excel.

The public workbook uses fictional employee data, generalized KPI names, fictional benchmarks, and fictional scoring weights. It is intended to demonstrate dashboard design, formula-driven KPI calculation, weighted scoring, trend reporting, coaching documentation, and repeatable manager workflows without exposing confidential or proprietary information.

The fictional employee data intentionally tells a performance story across twelve months, including steady improvement, a mid-year dip, recovery, and above-goal year-end performance so that the dashboard's trend and coaching features are visible in the demo.
